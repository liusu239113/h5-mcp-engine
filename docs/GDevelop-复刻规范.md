# GDevelop 式单机版复刻规范（Hexora）

> 目标：把 Hexora 的界面与交互按 GDevelop 移动版（github.com/4ian/GDevelop）一比一复刻，
> 做成独立「单机版」编辑器。模型系统保持**自己填 API**，不做订阅。
> 本文是调研产出 + 实施蓝图。全程本地开发、**完成前不推送**。

---

## 1. GDevelop 移动版的信息架构（对照其源码 newIDE/app/src）

| GDevelop 概念 | 源码目录 | 移动版表现 |
| --- | --- | --- |
| App 主框架 | `MainFrame/` | 顶栏（菜单/主页/场景页签/Ask AI）+ 工具行 + 画布 + 底部面板 |
| 对象列表 | `ObjectsList/` | 底部面板「对象」：搜索框 + 全局对象 + 场景对象（+ 新建） |
| 图层面板 | `LayersList/` | 底部面板「图层」 |
| 场景编辑 | `SceneEditor/` `InstancesEditor/` | 画布上的场景与实例 |
| 属性编辑 | `PropertiesEditor/` | 底部面板「属性」 |
| 资源 | `ResourcesList/` `ResourcesEditor/` | 底部面板「素材」 |
| 项目创建 | `ProjectCreation/` | 启动流里的「模板 / 选布局」 |
| 项目存储 | `ProjectsStorage/` | 最近项目 / 打开 / 保存 |
| AI | `AiGeneration/` | 顶栏 Ask AI（订阅制）→ **我们改为自填 API 的 AI 对话** |

### 底部图标栏（移动版 5 格，据截图）
`对象(📦) · 3D/实例(🧊) · 编辑(✏️) · 属性(⋮≡) · 图层(🗂)`
→ 我们映射为：`对象 · 素材 · 编辑 · 属性 · 图层`（不做假按钮，全部接真实功能）

### 顶栏（两行）
- 第一行：`☰ 菜单 · ⌂ 主页 · [场景页签…] · Ask AI`
- 第二行（工具）：`历史/撤销 · 保存 · ▶ 运行 · 预览 · 2D|3D · ↶↷ · 缩放`

## 2. Hexora 目标结构（本次重做）

```
App
├── 首页 buildHomePage()            ← 新增（GDevelop 启动流）
│    ├── 最近项目（卡片列表）
│    ├── 新建项目 → 模板/布局选择（ProjectCreation 对应）
│    ├── 示例项目（demo）
│    └── AI 配置入口 → showSettings()
├── 编辑器 buildPreviewPage() 升级   ← 主战场
│    ├── 顶栏1：☰ 项目菜单 · ⌂ 首页 · 场景页签 · 🤖 AI
│    ├── 顶栏2（工具行）：撤销快照 · 保存 · ▶ 运行/重载 · 缩放 · ⛶ · ▤对象
│    ├── 画布：WebView（现有）
│    ├── 对象面板（现有，增强选中态/属性联动）
│    └── 底部图标栏：对象 / 素材 / 编辑 / 属性 / 图层
├── 对话页（AI）                     ← 保留（自填 API）
└── 发布页                           ← 保留
```

App 底部导航：`首页 · 编辑器 · 对话 · 发布`（替代原 对话·预览·发布）。

## 4. 硬性约束（用户要求）

1. 重做期间**不推送远端**（不触发 CI/Release）；完成后统一推送一次。
2. 模型配置保持**自填 API**（Key/Base URL/模型），不做订阅。
3. 对象面板必须**实时读取运行中的游戏**（已实现，保持）。
4. 不复刻 GDevelop 的 3D/事件系统等超大模块（不在本轮范围）。
