# 预制 UI 风格包（做界面之前必读）

**这个引擎自带 10 套 UI 主题。做任何界面之前，先从里面挑一套。**

⚠️ **禁止**用浏览器原生默认样式糊弄（灰色默认按钮、sans-serif 裸字号、`alert()` 当弹窗）。
挑一套主题是硬要求，不是建议。

---

## 怎么用（三步）

1. **看全部主题** → `game_read path=_ui/kit.json`
   里面有每套的 `id` / `name` / `font` / `scenes`（适用题材）/ `mood`（调性）。

2. **按题材挑一套** → 看 `scenes` 里有没有你这款游戏的题材。
   比如做武侠 → `ink`；做像素闯关 → `pixel16`；做太空 → `neon`。

3. **拿具体写法** → `game_read path=_ui/<id>/HOWTO.md`（写法手册）
   和 `_ui/<id>/theme.css`（真实色值）。

引用进游戏时把 `theme.css` 复制进工程，或者照着里面的色值写。
组件用 `_ui/shared/components.css`（公共组件）。

## 注意

- **`_ui/` 是只读的参考副本**（随 APK 分发）。要用就**复制**进你的工程，别直接改它 ——
  下次启动会被重新释放，改动会丢。
- 每套的 `HOWTO.md` 里有**具体写法**（不只是色值），比如 neon 的
  「发光用带颜色的阴影，不是加粗描边」这种关键手法 —— 光抄色值是抄不出味道的。
- 用户如果在设置里换过主题（`ui-kits` 里那套会被写进项目），以**项目里那份**为准。

## 和另外几份 UI 文档的关系

| 文档 | 什么时候用 |
|---|---|
| **本份 + `_ui/kit.json`** | **优先** —— 有现成的就先用现成的 |
| `ui-astroon.md` / `ui-brawlforge.md` / `ui-pixelforge.md` | 题材不在这 10 套里，或用户点名要这几种风格时 |
| `ui-design-spec.md` | 通用规范（字号 / 间距 / 对比度），挑完主题后用来做细节 |
